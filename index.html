HOI4 Game Log Parser

Select a Hearts of Iron IV save folder, watch for autosaves, then export a game-log zip for rendering.

Version: v25 usability layout + wake lock

Host setup checklist

  1. Before the game: make sure the host keeps at least 3 autosaves / debug_saves = 3 or higher. One overwriting autosave can cause missed history.
  2. Open this page in Chrome or Edge. GitHub Pages is best. Local file opening can work, but live folder access is more reliable from a hosted page or localhost.
  3. Click “Select save folder”. Choose the HOI4 save folder shown below.
  4. At the start of the session, click “Watch new saves only”. This ignores old saves and records new/changed autosaves as the game runs.
  5. Leave the parser tab open and visible if possible. The app will try to keep the screen awake while watching.
  6. At the end, click “Download gamelog export.zip”. Send that zip to whoever is making the animation render.
