HOI4 Game Log Parser

Select a Hearts of Iron IV save folder, watch for autosaves, then export a game-log zip for rendering.

Save folder location

Typical Windows folder:

Documents\Paradox Interactive\Hearts of Iron IV\save games

The browser can only read files/folders you manually select. Normal .hoi4 binary saves are attempted using the experimental local binary fallback; no change to HOI4 save settings is required. After selecting the folder, use “Watch new saves only” at the start of a session to ignore existing autosaves and capture new/changed autosaves as the game runs.
